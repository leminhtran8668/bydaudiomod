# BYD Audio Mod

App gộp **Âm thanh cửa** + **Audio Feedback** cho xe BYD DiLink (Dolphin và tương thích).

**Tác giả:** Lê Minh

## Tính năng

### Tab Loa Trong / Loa Ngoài
- Tùy chỉnh âm thanh khi mở/đóng cửa, khoá/mở khoá
- Loa trong xe: chọn file audio riêng + volume
- Loa ngoài (AVAS): 8 pattern (ding-dong, còi, fanfare…)

### Tab Phản hồi
- Âm thanh hộp số (P/R/N/D)
- ACC (hành trình)
- BSD (điểm mù)
- Cảm biến lùi
- Thu hồi năng lượng / mặt đường
- Chế độ lái (Sport…)

### Tab Tác giả
- Thông tin tác giả: **Lê Minh**
- ADAS Monitor
- Reflection Test (dev)

## Cài đặt lên xe BYD

1. Copy APK vào thư mục `Third Party Apps 55/` trên USB
2. Cắm USB vào xe
3. Nhập mật khẩu: `BYD6125F`
4. Cài đặt APK

## Build

Xem `build.sh` hoặc workflow GitHub Actions.
